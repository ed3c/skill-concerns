# Portable falsification kernel (L0 procedural)

One domain-free kernel per SKILL.md clause, in clause order. No repository
name, no provider, no file path from any product: what stays here is the
decision an agent makes, wherever it is standing.

- K1 Rules a monitor enforces are bytes read at a commit, not memory recalled into a prompt. If it is not in the pinned catalogue at that commit, this pass does not enforce it.
- K2 A pattern match is a hypothesis. Report the class only with its experiment attached: exact subject, the command sequence that ran, what was expected, what was observed.
- K3 Read the subject, write only in a throwaway copy, and prove the read-only property by digesting the subject before and after. A pass that mutated its subject refuses its own report rather than publishing it.
- K4 A finding is a record with a fixed grammar, judged by something other than what wrote it. Prose with a number attached is not a finding; a record whose observed half is missing is not one either.
- K5 An escalation is a bounded, structured signal to whoever holds stop authority. The urgent classes are enumerated in the contract, and the signal carries no instruction and no patch.
- K6 A rule set grows only from an adjudicated verdict and shrinks only when a machine takes the class over. Detection is where adjudication begins; a class whose gate has landed leaves active sampling.
- K7 An instrument measures its own effect and reports the failure to bend the curve. Fewer observations than the declared minimum is not-yet-evidence, never a green.
